# Варианты ИИ-помощника CallMe

**Обновление:** все четыре варианта теперь полноэкранные; описание исходных компоновок ниже сохранено как история.

Отдельная страница: http://127.0.0.1:3001/assistant.html.

Четыре варианта кнопки и окна:

1. «Всегда рядом»: подписанная кнопка внизу справа, боковой Sheet.
2. «Лёгкое касание»: круглая кнопка, плавающее окно из Card, доска остаётся доступна.
3. «В центре внимания»: широкая кнопка внизу по центру, центральный Dialog.
4. «Место для разговора»: пункт рядом с доской, отдельная область чата.

В галерее показаны миниатюры, полноразмерные интерактивные примеры и выбор варианта с сохранением в localStorage. Повторное нажатие «Выбрано» снимает выбор. В каждом примере доступны стартовый экран, переписка, быстрые запросы, текстовый ввод, закрытие и повторное открытие. Голосовая кнопка объясняет режим предпросмотра, микрофон не запрашивается. Ответы заданы локальным сценарием, реальные записи не создаются, внешние AI API не вызываются. Основной интерфейс приложения не переключается на вариант автоматически.

Компоненты: shadcn Button, Card, Avatar, Badge, Alert, InputGroup, ToggleGroup, Sheet, Dialog, Message, Bubble и MessageScroller. Используется тема приложения. Новых зависимостей нет.

## Полноэкранные варианты — 30.10.2026

«Посмотреть» сразу открывает помощника во всю область браузера. Первый вариант использует полноширинный Sheet, остальные — Dialog без внешних отступов и ограничений ширины. Боковые быстрые запросы первого и четвёртого вариантов видны на десктопе; на телефоне запросы доступны внутри чата. Верхняя панель содержит возврат к галерее, показ кнопки запуска на доске и выбор варианта. Ввод закреплён внизу, прокручивается область разговора.

Выполнены возврат к доске, повторное открытие и отправка текста. Сборка успешна, линтер без ошибок с 9 прежними предупреждениями.

## Помощник на главном экране — 30.10.2026

Новый самостоятельный вариант: http://127.0.0.1:3001/assistant-board.html. Полноэкранная доска с узкой навигацией, подписанной кнопкой помощника снизу по центру и закрываемой панелью справа. На десктопе панель занимает 400 px без затемнения; до 1024 px используется shadcn Sheet. Главная кнопка, крестик и Escape закрывают чат. Переписка и черновик сохраняются между открытиями в пределах текущей страницы. Из карточки доступно действие «Обсудить с помощником». Выбор варианта сохраняется в localStorage; основной интерфейс приложения автоматически не меняется.

Официальные референсы: [Notion Agent](https://www.notion.com/en-gb/help/notion-agent) — нижняя кнопка и боковой чат; [Asana Smart Chat](https://help.asana.com/s/article/ai-chat) — готовые стартовые запросы. Состав интерфейса: существующие shadcn Sidebar, Card, Button, Sheet, Dialog, Avatar, Badge и компоненты чата. Новых зависимостей нет.

Это предпросмотр дизайна: задачи примерные, ответы сценарные, внешний AI и микрофон не вызываются. Голосовая кнопка показывает пояснение.

Проверено: сборка и линтер завершились успешно; desktop 1440×900 и mobile 390×844, светлая и тёмная темы; открытие и закрытие, Escape с возвратом фокуса, сохранение черновика и разговора, быстрый запрос, переход из карточки в обсуждение. При мобильной ширине scrollWidth документа равен ширине экрана. Ошибка TooltipProvider обнаружена при первом открытии и исправлена в точке входа; после исправления экран и панель отображаются. API-тесты не запускались, backend не изменялся.

Файлы: `src/components/assistant-board-preview.tsx`, `src/assistant-board-main.tsx`, `assistant-board.html`, `vite.config.ts`; общий Chat расширен в `src/components/assistant-gallery.tsx`.
