> Дополнение от 30.10.2026: по новому поручению реализованы CallMe, аккаунты и совместная работа. Актуальные правила и проверка — [callme-team.md](callme-team.md). Указания ниже об отсутствии регистрации относятся к предыдущему этапу.
Реализовано и проверено 30.10.2026 по дополнительному поручению пользователя. Телемост согласован для созвонов; Telegram и Яндекс Заметки — для связанных материалов.

## Пользовательские сценарии

| Запрос | Реализация |
|---|---|
| Открывающееся боковое меню | Официальный Sidebar shadcn/ui, скрытие на десктопе и Sheet на телефоне; скрытое меню исключено из клавиатурного обхода через inert |
| Разные проекты | Создание проекта, список в меню, выбор проекта сверху, «Все проекты» и «Без проекта»; сохранение на сервере |
| Основной экран — канбан | Card + Badge + Select: «К выполнению», «В работе», «Готово»; перетаскивание мышью и выбор статуса с клавиатуры; возврат из готовых |
| Удобство на телефоне | Переключатель колонок, прокрутка списка внутри колонки, полная ширина чата, прокручиваемая форма |
| Планы | Существующий список задач, встреч и напоминаний с фильтрами доступен отдельным пунктом меню и учитывает проект |
| Чат поверх доски | Sheet + MessageScroller + Message + Bubble; текстовые команды, уточнения, история, ошибки и подтверждения; незавершённое уточнение восстанавливается при перезагрузке |
| Голос из чата и отдельной кнопкой | Общая VoiceSession и явное сообщение, если сервис не настроен; при закрытии чата сессия останавливается |
| Ссылка на созвон | Отдельное поле Телемоста, проверка HTTPS и домена/пути, открытие сохранённой ссылки из карточки и формы |
| Связанные материалы | До 12 ссылок: Telegram, Яндекс Заметки, другой материал; название, адрес, изменение, удаление из записи и открытие |
| Настройки | Возможности сервисов и рабочий выбор светлой/тёмной темы, сохранение в этом браузере |

Новые задачи/встречи из чата относятся к проекту, выбранному при создании. Проект сохраняется через уточнение длительности или подтверждение распознанной речи. Поиск чата охватывает всё пространство, что явно указано в его заголовке. Переключение проекта не перемещает ранее созданные записи. Выбор фильтра проекта после перезагрузки возвращается к «Все проекты».

## Что именно означает подключение сервисов в этой версии

Работает хранение и открытие связанных ссылок. OAuth-аккаунты не подключены, содержимое внешних сервисов не импортируется. В интерфейсе нет фиктивного состояния «Подключено».

Сценарий созвона: открыть форму → открыть Телемост в новой вкладке → создать встречу в самом Телемосте → скопировать ссылку → вставить в поле → сохранить запись. В карточке появляется переход «Телемост». Формат адреса проверяется, существование встречи и права доступа не проверяются приложением.

Telegram принимает HTTPS-ссылки t.me/telegram.me с непустым путём; поддержка ссылок описана в [официальной документации Telegram](https://core.telegram.org/api/links). Автоматической отправки сообщений нет. Для Яндекс Заметок сохраняется предоставленный пользователем HTTPS-адрес; наличие публичного доступа и отдельного API заметок не утверждается. Переход на [страницу заметок](https://disk.yandex.ru/notes) может требовать входа.

Для последующего автоматического создания созвона потребуется отдельное подключение аккаунта: OAuth-приложение, серверное хранение токена, привязка к владельцу пространства и подтверждение внешнего действия. [Документация доступа Телемоста](https://yandex.ru/dev/telemost/doc/ru/access) указывает право `telemost-api:conferences.create`; [операция создания](https://yandex.ru/dev/telemost/doc/ru/conferences/conference-create) возвращает `join_url`. Это направление интеграции, а не реализованный OAuth или успешный живой вызов. Доступность операции для конкретного аккаунта/тарифа не проверена. Локальное сохранение задачи не должно зависеть от успеха создания внешней встречи; ошибка должна сохранять черновик без выдуманной ссылки.

- `npm run build`: успешны TypeScript клиента/сервера и production-сборка Vite. После расширения тестов отдельно выполнен `npx tsc -p tsconfig.server.json` — успешно.
- `npm run lint`: **0 ошибок, 9 прежних предупреждений** в shadcn-компонентах и use-mobile; правила не отключались.
- Собранный клиент открыт по http://127.0.0.1:3001/. Сервер перезапущен с итоговым кодом; проект, три проверочные записи, статусы и ссылки сохранились.
- Браузер: 1440×900 и 390×844, измеренный scrollWidth равен ширине viewport. Финальный журнал браузера не содержит ошибок/предупреждений приложения.

Добавленные API-проверки:

1. Создание и сохранение проекта, повторы requestId без дублей, запрет дубликатов имени и чужого projectId.
2. Перемещения между всеми колонками, возврат из готовых, синхронизация completed/status, запрет устаревшего revision и сохранение исходных дат/полей.
3. Сохранение трёх видов материалов и ссылки на созвон через подтверждение прошлой даты, редактирование, снятие проекта и удаление ссылок.
4. Запрет javascript/data/http-ссылок, адресов с credentials, ложного домена Телемоста, некорректного Telegram и более 12 ссылок.
5. Проект в текстовом создании встречи, в уточнении и подтверждённой речи; изменение существующей записи не переносит её в текущий проект.
6. Максимальные 12 материалов с адресами длиной 2048 символов проходят реальную HTTP-границу и сохраняются.

Дополнен контракт модели: ответ YandexGPT не может создавать проект, перемещать статус или выдумывать projectId/ссылку на созвон.

В браузере выполнены:

- Пустое имя проекта → ошибка; создание «Проверка новой доски» → отдельная пустая доска.
- Создание задачи с Телемостом и материалами Telegram/Яндекс Заметок; неверный домен созвона отвергнут до сохранения.
- Выбор «В работе» через Select; реальное перетаскивание мышью в «Готово»; выбор статуса клавишей Enter на мобильном размере.
- Чат → задача на завтра; чат → встреча без длительности → «30 минут» → встреча сохранена в выбранном проекте.
- Меню и фильтр проекта, мобильное переключение колонок; открытие сохранённой задачи после перезагрузки и изменение названия материала в мобильной форме.
- Голосовая кнопка внутри чата и отдельная на доске → явное сообщение об отсутствии подключения, текстовый ввод остаётся доступен.
- «Удали её» → конкретная запись в AlertDialog поверх чата → отмена. Финальное удаление подтверждается API-тестами, вручную в этом прогоне не выполнялось.
- Тёмная тема → перезагрузка → тема сохранена; возвращена светлая тема.
- Незавершённое уточнение → перезагрузка → чат автоматически открыт с тем же вопросом; черновик отменён.
- Скрытие десктопного меню → его элементы исчезли из дерева доступности; открытие возвращает навигацию.

Исправлены найденные при осмотре проблемы: сжатие карточек в прокручиваемой колонке (shrink-0), доступность скрытого Sidebar (inert), ширина мобильной шапки и приоритет ширины чат-панели.

## Обновление карточки «Рабочая» — 30.10.2026

Основная доска и вариант «Рабочая» в галерее используют общий `TaskCard`, составленный из shadcn Card, Badge, Avatar и Button. На карточке: название, до четырёх строк описания, приоритет, срок и исполнитель. Статус определяется колонкой; единственная кнопка карточки — «Открыть». В форме добавлено описание до 4000 символов, которое сохраняется в SQLite; прежние записи показывают «Без описания».

При перетаскивании источник приподнимается, полупрозрачный след остаётся в колонке, переносимый образ получает тень и небольшой наклон. Колонка назначения подсвечивается. Учитывается reduced-motion. Перенос также доступен клавиатурой: фокус карточки → пробел → стрелки → Enter, Escape отменяет. На телефоне перенос доступен через «Открыть» → «Переместить в колонку»; несохранённые изменения требуется сначала сохранить.

### Открытие нажатием на карточку

По следующему уточнению пользователя удалена отдельная кнопка «Открыть» у рабочей карточки. Вся поверхность карточки открывает запись; Enter работает с клавиатуры. Пробел со стрелками остаётся способом переноса. После drag-and-drop подавляется случайный click, последующее обычное нажатие открывает форму. Вариант «Рабочая» в галерее использует то же поведение.

Проверено в браузере: клик по описанию, Enter, перенос клавиатурой и мышью без открытия формы, обычный клик после переноса и открытие при ширине 390 px. `npm run build` успешен, `npm run lint` — без ошибок с 9 прежними предупреждениями.
