# CallMe — задачи, встречи и команда

Локальное веб-приложение по `Спецификация_голосового_ассистента.md`: канбан по проектам, встроенный чат, задачи, встречи, напоминания и гостевое пространство. По дополнительному поручению добавлены аккаунты, команды, приглашения, роли, исполнители и приоритеты. Интерфейс собран из официальных компонентов **shadcn/ui (Radix Nova)**, добавленных CLI; альтернативных UI-наборов нет.

## Текущий результат

Работают текстовые команды ограниченного локального обработчика и формы, импорт исходных 1000 событий, поиск по словам, список по периодам, уточнения, изменение, выполнение и подтверждаемое удаление. Данные и история сохраняются на сервере в SQLite; идентификатор гостевого пространства или сессии аккаунта хранится в HttpOnly cookie, а тема оформления — локально в браузере.

Серверные адаптеры YandexGPT и SpeechKit реализованы, но **живые API-вызовы не проводились**. Без разрешения на платные обращения они выключены. Локальный обработчик не является LLM и не заменяет проверку свободного диалога. Работа физического микрофона, точность русского распознавания, синтез и перебивание пока не подтверждены. Публичная публикация не выполнялась.

## Варианты карточек

Отдельная страница для сравнения шести компоновок: **http://127.0.0.1:3001/cards.html** (в режиме разработки — порт 5173). Переключаются примеры, светлая/тёмная тема, статус и приоритет демонстрационной задачи. Можно отметить понравившийся вариант. Страница не обращается к API и не меняет рабочие записи; выбор сбрасывается при перезагрузке. Исходники: `cards.html`, `src/cards-main.tsx`, `src/components/task-card-gallery.tsx`.

## Команда и аккаунты

При первом открытии предложено создать аккаунт по имени пользователя и паролю. Окно можно открыть позднее через **Настройки и сервисы → Команда → Создать аккаунт**. Текущие гостевые проекты и записи станут командным пространством; гостевая cookie больше не даёт к ним доступа. Старые аккаунты продолжают входить по почте и прежнему паролю. Владелец создаёт одноразовую ссылку для участника или наблюдателя и передаёт её самостоятельно. Ссылка действует 7 дней, её можно отозвать. Приглашённый создаёт аккаунт либо входит в существующий.

- Владелец управляет названием команды, приглашениями, ролями и исключением участников.
- Участник читает и редактирует все записи команды; наблюдатель только просматривает. Права проверяются сервером.
- У записи есть исполнитель из владельцев/участников и приоритет: низкий, обычный, высокий, срочный. На доске доступны фильтры, срочные записи идут первыми.
- Данные команды обновляются каждые 5 секунд в активной вкладке. История чата, выбор записи и подтверждения отдельные у каждого аккаунта. Устаревшие изменения отклоняются.
- При исключении участника или переводе в наблюдатели задачи сохраняются без исполнителя. Если пользователь состоит в нескольких командах, в настройках доступно переключение.

Подробности: [аккаунты, команда и проверка](docs/callme-team.md). Приложение запущено локально; ссылка `127.0.0.1` доступна только на этом компьютере. Для работы с других устройств нужен отдельно согласованный общий адрес сервера. Публикация не выполнялась.

## Доска, проекты и связанные сервисы

- Главный экран — канбан «К выполнению / В работе / Готово». Карточки перемещаются мышью или через выбор статуса; на мобильном колонки переключаются сверху.
- Выдвижное меню содержит проекты, планы и настройки. Проект создаётся через «Новый проект»; верхний список выбирает проект, все проекты или записи без проекта.
- Разговор с ассистентом открывается в основной области. Новые записи из текста и подтверждённой речи относятся к выбранному проекту; поиск в чате охватывает всё пространство. Существующие записи не меняют проект от переключения фильтра.
- В форме есть отдельная ссылка на созвон в Телемосте и до 12 связанных материалов: Telegram, Яндекс Заметки, другие HTTPS-ссылки. Их можно добавить, изменить, удалить из карточки и открыть.
- «Открыть Телемост» открывает сам сервис в новой вкладке; ссылку `/j/…` можно вставить в карточку. В настройках подготовлено отдельное OAuth-подключение и создание публичной встречи после подтверждения; работа API для конкретного аккаунта ещё не проверена. Telegram и Заметки работают как связанные ссылки, без чтения и синхронизации содержимого.
- В настройках доступны ссылки на Яндекс Календарь, Диск, Почту, Карты, Телемост и Заметки. Для Календаря и Диска подготовлены личная OAuth-авторизация и отдельные проверки доступа. Синхронизация событий и файлов не реализована. Почта, Карты и Телемост пока открываются по ссылкам.

Проекты, статусы и ссылки сохраняются в SQLite без сброса старых данных. Старые записи без новых полей отображаются без проекта; выполненные попадают в «Готово», остальные — в «К выполнению». Проверочные записи не добавляются в исходный CSV.

Подробности и текущая проверка: [канбан и сервисы](docs/kanban-and-services.md).

### Локальное подключение Яндекс Календаря и Диска

Вход в аккаунт CallMe обязателен: подключение привязывается к пользователю, а не ко всей команде. Укажите идентификатор существующего OAuth-приложения в `YANDEX_CALENDAR_DISK_CLIENT_ID` в локальном `.env` и запустите сервер; приложению в Яндекс OAuth нужен адрес возврата `http://127.0.0.1:8765/api/yandex/callback` и права `cloud_api:disk.read` и `calendar:all`. Порт 8765 должен быть свободен. В настройках сервисов нажмите «Подключить Яндекс»; отдельно проверьте Диск и Календарь соответствующими кнопками. Сохранённая авторизация сама по себе не подтверждает доступ к API.

OAuth использует PKCE и одноразовое состояние. Токен зашифрован в SQLite, ключ хранится отдельно в `data/.yandex-vault/key` с ограниченными правами; `.env`, база и ключ исключены из Git. Не передавайте их вместе с исходным кодом. После истечения токена потребуется повторное подключение. Кнопка отключения удаляет локальный токен; отозвать разрешение у Яндекса можно в настройках Яндекс ID. Доступ к календарям включает изменение событий; в этой версии доступны выбор календаря и предварительный просмотр части событий без синхронизации. Повторы, события с участниками и неподдерживаемые часовые пояса исключаются из просмотра. 31.10.2026 на одном аккаунте проверено чтение корня Диска и получение ответа CalDAV; запись и синхронизация не проверялись.

Подготовлены отдельные подключения Почты и Телемоста с переменными `YANDEX_MAIL_CLIENT_ID` и `YANDEX_TELEMOST_CLIENT_ID`. Для Почты нужны `login:email` и `mail:imap_ro`; при авторизации также допускается `login:info`, если он включён в существующем приложении Яндекса. Для Телемоста нужны `telemost-api:conferences.read` и `telemost-api:conferences.create`, а также тот же адрес возврата. 31.10.2026 на одном аккаунте проверены авторизация, количество писем и просмотр списка входящих через IMAP. Создание встречи в Телемосте требует подтверждения и сохраняет результат с защитой от повтора того же запроса. При потере ответа его результат неизвестен — перед новым запросом проверьте Телемост. Создание встречи пока проверено только с имитацией сервиса.

## Запуск

Требуется Node.js 24.20+ и npm. Используется встроенный `node:sqlite`.

```bash
npm ci
npm run dev
```

Откройте **http://127.0.0.1:5173/**. Vite перенаправляет `/api` на локальный сервер 3001. Ключи для локального режима не требуются. `data/events.csv` включён в проект; новые пространства получают все 1000 записей.

Собранное приложение:

```bash
npm run build
npm start
```

Откройте **http://127.0.0.1:3001/**. Сервер отдаёт `dist/` и API. Не используйте `npm run preview` для проверки приложения целиком: это только статический Vite preview без API-прокси.

Проверки:

```bash
npm test
npm run build
npm run lint
```

## Примеры локальных запросов

- `Создай задачу купить молоко завтра`
- `Добавь задачу прочитать книгу без срока`
- `Напомни купить билет завтра в 10:00`
- `Создай встречу с командой завтра в 15:00` → уточнение → `30 минут`
- `Покажи планы на неделю`
- `Найди техническое задание` → выберите результат кнопкой или номером.
- `Перенеси её на завтра`
- `Отметь её выполненной`
- `Удали её` → подтверждение конкретной записи или `Отмена`.

Формы доступны через «Новая запись» и кнопку открытия в списке. Задача может не иметь срока либо иметь дату без времени. Встреча требует даты, времени и длительности. Прошедшая дата и пересечение требуют подтверждения. Напоминания **не доставляют уведомления**.

Локальный текстовый обработчик распознаёт ограниченные формы команд с глаголами создания, поиска и изменения. Для неизвестной либо незаконченной фразы он задаёт вопрос. Произвольные перефразировки требуют YandexGPT. Поиск использует нормализацию и простое отсечение русских окончаний; он не называется семантическим, синонимы не гарантируются. Поиск на доске и в планах — подстрока названия; в чате — слова с нормализацией.

## Подключение Yandex после разрешения на платные вызовы

Скопируйте `.env.example` в `.env` и задайте параметры **на сервере**. Не помещайте ключ в `VITE_*`, клиентский код или URL. `npm run dev` / `npm start` читают `.env` автоматически.

- `ALLOW_PAID_API=true` — явное включение платных обращений владельцем после согласования.
- `YANDEX_API_KEY` — ключ сервисного аккаунта с правами для используемых моделей и SpeechKit.
- `YANDEX_MODEL_URI` — полный URI конкретной доступной модели и версии. Не задан по умолчанию; проверить доступ и стоимость перед запуском. Версию нельзя считать проверенной по одному имени.
- `YANDEX_VOICE` — голос синтеза, по умолчанию `alena`; доступность требует живой проверки.
- `API_BUDGET_RUB` — не более 1000 ₽.
- `API_GPT_MAX_RUB_PER_CALL`, `API_STT_MAX_RUB_PER_CALL`, `API_TTS_MAX_RUB_PER_CALL` — положительные консервативные верхние оценки цены одного ограниченного запроса. Их нужно рассчитать по тарифу выбранной модели и максимальному входу **до включения**. Без оценок обращения блокируются.

В SQLite ведётся общий для всех пространств резерв расходов. Он записывается **до** отправки запроса и не возвращается при ошибке: провайдер мог уже выполнить работу. Следующий запрос, превышающий лимит, блокируется. Это не API биллинга и не доказательство фактической стоимости. Для публичного запуска дополнительно нужен лимит/контроль расходов в Yandex Cloud; изменения тарифов могут обесценить введённые оценки.

YandexGPT REST `foundationModels/v1/completion` получает только ограниченную историю, выбранную запись и черновик; она возвращает ответ на обычный вопрос или JSON-команду для работы с записями. Zod и доменный обработчик проверяют результат. Если ответ не соответствует схеме, ассистент просит уточнение и не изменяет записи. Модель может извлекать описание и приоритет; перенос по колонкам также поддерживается локальным обработчиком. Модель не может самостоятельно подтвердить действие, выбрать пользователя по идентификатору или получить чужое пространство. Упоминание `@имя` или фраза «исполнитель Имя» назначает единственного совпавшего участника исполнителем создаваемой или изменяемой задачи. Неоднозначное имя и наблюдатель отклоняются; уведомления не отправляются.

SpeechKit STT v1 принимает PCM 16 kHz mono. Браузер собирает короткие сегменты после паузы; фрагмент длиннее 20 секунд отбрасывается как потенциально оборванный. Пустой результат не запускает команду и не показывает ошибку. API v1 не отдаёт confidence, поэтому распознанный текст перед изменением проверяется пользователем кнопкой или отдельной фразой «да, верно». Голосовое подтверждение привязано к действию, ожидавшему подтверждения в начале фразы. TTS v1 озвучивает только сохранённый ответ; длинный ответ воспроизводится по частям. Пока звучит ответ и короткое время после него, микрофон не передаёт речь на распознавание, чтобы динамик не перебивал синтез и не подтверждал действия. Разговор можно остановить основной кнопкой. Чувствительность микрофона выбирается в настройках сервисов и применяется при следующем запуске разговора. Шумоподавление зависит от браузера; определение речи по уровню звука не распознаёт личность говорящего и не гарантирует отсечение чужой речи. Аудио на диск не записывается.

Отдельная кнопка записи захватывает до 20 секунд и помещает результат распознавания в поле ввода для проверки и исправления перед отправкой. Через команды `@Диск покажи файлы`, `@Календарь покажи календари` и `@Почта проверь почту` можно просматривать доступные данные подключённых сервисов; результаты показываются временно и не передаются языковой модели. На Диске можно открыть папку и прикрепить выбранный файл или папку к выбранной записи. Это частная ссылка на интерфейс Диска: права не меняются, участникам потребуется собственный доступ к материалу; после перемещения файла путь может измениться. Синхронизация календарей, отправка почты и создание файлов этими командами не выполняются.

Команда `@Почта покажи письма` отображает до 20 последних входящих. Выберите задачу и письмо: ссылку можно прикрепить к записи, а текст — просмотреть, отредактировать и отдельно добавить в конец её описания. В описании текст виден участникам команды. Ссылка CallMe открывает письмо только владельцу подключённого ящика; это не ссылка на веб-интерфейс Яндекса. Открываются письма до 2 МБ из текущей папки «Входящие», без изменения статуса прочитанности; вложения в карточку не копируются. При смене ящика, удалении или переносе письма ссылка может перестать работать. Содержимое не сохраняется на сервере при просмотре, но сохраняется в общей задаче после подтверждения переноса.

## Данные и приватность

- Оригинальный CSV скачан с [ссылки задания](https://clck.ru/3WTtAk), без изменения байтов; источник и хеш — в `docs/requirements.md`.
- Импорт сохраняет оригинальные `id`, `text`, `date`, `time`; одинаковые названия не объединяются. Тип предположен по началу фразы, длительность неизвестна. Повторный импорт не восстанавливает удалённые записи и не перезаписывает изменения.
- Ключ cookie содержит 256 случайных бит; на сервере хранится SHA-256 этого ключа. IP для идентификации не используется. Cookie действует год, `SameSite=Strict`, `HttpOnly`; для HTTPS необходимо `COOKIE_SECURE=true`.
- История, контекст и события хранятся в `data/app.sqlite` и сопутствующих WAL-файлах. Файлы исключены из Git. Для резервирования используйте SQLite backup либо остановите сервер перед копированием базы.
- Очистка cookie теряет доступ только к гостевому пространству. Зарегистрированные пользователи входят с именем и паролем или, для прежних аккаунтов, с почтой и паролем на любом устройстве, имеющем доступ к тому же серверу. Восстановление пароля и подтверждение почты не подключены. Автоудаление истории не настроено: срок хранения нужно согласовать до публичного запуска. Захваченный звук живёт в памяти только до обработки/остановки; отправленные данные регулируются также политикой Yandex.
